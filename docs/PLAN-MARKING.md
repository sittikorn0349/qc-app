# ตรรกะการระบุตำแหน่งบนแบบแปลน (รุ่น 2)

ไม่บังคับใช้ ทุกรายงานต้องใช้ได้ครบโดยไม่มีแบบแปลน

## 1. ข้อมูล
- **แผ่นแบบ (sheet)** `{a, name, w, h, zone?}` — 1 หน้าของแบบ เก็บอยู่ในรายงาน เพื่อให้รายงานเก่าแสดงแบบที่ใช้ตอนตรวจเสมอ (แบบออกใหม่ไม่ย้อนไปเปลี่ยนรายงานเก่า)
- **หมุด (pin)** `pins[itemId] = [{s, x, y}]` — `s` = ลำดับแผ่น, `x, y` = สัดส่วน 0–1 ของภาพ (ไม่ขึ้นกับขนาดจอ)
- แบบที่เคยใช้ในรายงานอื่นของโครงการเดียวกัน แสดงให้เลือกใช้ซ้ำได้ทันที ไม่ต้องอัปโหลดใหม่

## 2. กฎของหมุด
1. **1 รายการ = 1 หมุด** (ตำแหน่งของจุดที่พบ) วางใหม่ = ย้ายหมุดเดิม
   ข้อมูลเก่าที่มีหลายหมุด: แสดงทุกหมุด แก้/ลบทีละหมุดได้ ไม่หายเอง
2. **ไม่วางทันทีเมื่อแตะ** แตะบนแบบ = หมุดชั่วคราว (เส้นประ) + แถบยืนยัน "วางหมุดรายการที่ N ตรงนี้" ลากหมุดชั่วคราวเพื่อปรับได้ กดยืนยันจึงบันทึก
3. **แตะหมุด** = เปิดเมนูของหมุดนั้น: ชื่อรายการ สถานะ · "เลือกรายการนี้" · "ย้าย" · "ลบหมุด" (ลบแล้วมีปุ่มเลิกทำ 6 วินาที) ไม่มีการลบด้วยการแตะครั้งเดียว
4. **สีหมุดตามสถานะ** แดง = ต้องแก้/ไม่ผ่าน · ฟ้า = รอตรวจซ้ำ · เขียว = ผ่าน/ปิดแล้ว · เทา = ยังไม่ลงผล · รายการที่กำลังเลือกมีวงขอบหนา
5. รายการที่ถูกลบ (อยู่ในถังขยะ) ไม่แสดงหมุดและไม่ออกใน PDF แต่ข้อมูลหมุดยังเก็บไว้ กู้คืนรายการแล้วหมุดกลับมา
6. เอกสารที่ดูอย่างเดียว (ของคนอื่น) ดูหมุดได้ วาง/ย้าย/ลบไม่ได้

## 3. การเลือกแผ่นเมื่อเปิด
1. แผ่นที่รายการนี้มีหมุดอยู่
2. แผ่นที่ชื่อหรือชั้นตรงกับโซนในช่องตำแหน่ง (เช่น "ชั้น 2 · เสา C-3" → แผ่นที่ชื่อมี "ชั้น 2")
3. แผ่นที่เปิดล่าสุด

## 4. การดูแบบ
- เปิดมาเต็มจอ (พอดีจอ) ถ้ารายการมีหมุดแล้ว ซูมไปที่หมุด
- มือถือ: 2 นิ้วถ่างซูม · 1 นิ้วลากเลื่อน · แตะ 2 ครั้งซูม · คอม: ล้อเมาส์ซูมตรงตำแหน่งเมาส์ · ลากเลื่อน
- ปุ่ม − / พอดีจอ / + · ซูมได้ถึง 8 เท่า · หมุดขนาดคงที่ไม่ว่าซูมเท่าไร
- แถบล่าง: "รายการที่ 1 / 12 · ระบุแล้ว 5 · ยังไม่ระบุ 7" · ก่อนหน้า / ถัดไป / "ไปรายการที่ยังไม่ระบุ"

## 5. จัดการแผ่น
- เพิ่ม: รูป / ไฟล์ PDF (ทุกหน้าเป็นแผ่น สูงสุด 20 หน้า) / แบบที่มีในโครงการ
- เปลี่ยนชื่อแผ่น (เช่น "แปลนชั้น 2") · ลบแผ่น: ถ้ามีหมุดบอกจำนวนหมุดที่จะหายไปด้วย และเลิกทำได้

## 6. ผลลัพธ์
- **PDF รายงาน (ฉบับเต็ม / สรุปค้างแก้ / ลิงก์ให้คนนอก)**: ต่อท้ายด้วยหน้า "ตำแหน่งบนแบบ" แผ่นละหน้า เฉพาะแผ่นที่มีหมุดของรายการในฉบับนั้น เลขหมุด = ลำดับในตาราง สีตามสถานะ ใต้แบบมีตารางอธิบาย (ลำดับ · ตำแหน่ง · สถานะ)
- ในตารางรายการ ช่องตำแหน่งบอกว่า "ดูบนแบบ: <ชื่อแผ่น>"
- แผ่น A3 สำหรับช่าง (พิมพ์แยก) ยังมีเหมือนเดิม
- หน้าแชทของจุดตรวจ แสดงภาพแบบย่อพร้อมหมุดของจุดนั้น แตะเพื่อเปิดดูเต็ม

## 7. กรณีผิดปกติ
| กรณี | สิ่งที่แอปทำ |
|---|---|
| ภาพแบบยังไม่ถูกดาวน์โหลดมาเครื่องนี้ | แสดงกรอบว่า "แบบยังไม่มาถึงเครื่องนี้ · ต่อเน็ตแล้วเปิดใหม่" ไม่ให้วางหมุดบนกรอบว่าง · PDF ข้ามหน้านั้นพร้อมหมายเหตุ |
| ไฟล์ PDF เปิดไม่ได้ / มีรหัสผ่าน | บอกให้บันทึกเป็นรูปแล้วเพิ่มใหม่ |
| ครั้งแรกยังไม่เคยต่อเน็ต (ยังไม่มีตัวอ่าน PDF) | บอกให้ต่อเน็ตครั้งเดียว · เพิ่มรูปได้ตามปกติ |
| PDF เกิน 20 หน้า | เพิ่ม 20 หน้าแรก บอกจำนวนหน้าที่เหลือ |
| อีกเครื่องแก้รายงานเดียวกันขณะเปิดหน้าแบบ | ยึดรายการตาม id ไม่สลับรายการเอง |
| ลบแผ่นที่อยู่กลาง | เลื่อนเลขแผ่นของหมุดที่อยู่หลังให้ถูกต้อง |
