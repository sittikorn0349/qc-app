# แอปตรวจงานก่อสร้าง (ออฟไลน์ / PWA)

## วิธีติดตั้ง (ทำครั้งเดียว)
แอปต้องเปิดผ่านลิงก์ https เพื่อให้ติดตั้งและใช้ออฟไลน์ได้ ไม่ใช่ดับเบิลคลิกไฟล์ใน My Computer
ตัวอย่างฟรี: GitHub Pages
1. สร้าง repository ใหม่ใน GitHub (เช่น `qc-app`) แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไปที่ราก (index.html, sw.js, manifest.webmanifest, pwa-shell.js, pwa-extras.js, โฟลเดอร์ icons และ libs)
2. Settings > Pages > Branch: main / root > Save
3. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อ>.github.io/qc-app/`
4. เปิดลิงก์บนมือถือ/คอม ตอนมีเน็ตหนึ่งครั้ง แล้วติดตั้ง
   - Android/Chrome: เมนู > ติดตั้งแอป
   - iPhone/Safari: ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม
   - คอม Chrome/Edge: ไอคอนติดตั้งที่ช่อง URL
5. หลังจากนั้นเปิดได้โดยไม่ต้องมีเน็ต

## เปิดจากไฟล์โดยตรง (ไม่ติดตั้ง)
ดับเบิลคลิก index.html ก็เปิดใช้งานและเห็นรูปได้ (เก็บข้อมูลในเบราว์เซอร์นั้น) แต่จะไม่มีการแคชแอปและติดตั้งไม่ได้ ควรใช้ลิงก์ https ตามขั้นตอนด้านบนถ้าต้องการใช้งานจริง

## หน้าแรกและหน้าแบบฟอร์ม
เปิดแอปแล้วเข้าหน้าแรกเสมอ มีเมนูเลือกแบบฟอร์ม การ์ด “ฉบับล่าสุด” และปุ่มสี่เหลี่ยม 9 ช่อง
(ฉบับใหม่, คลังเอกสาร, ส่งเอกสาร, ตรวจรอบใหม่, ทำสำเนา, รับไฟล์ ZIP, สำรอง/กู้คืน, ถังขยะ, ตั้งค่า)
ช่อง ส่งเอกสาร/ตรวจรอบใหม่/ทำสำเนา ทำกับฉบับล่าสุด หน้าแบบฟอร์มมีแถบบน: กลับหน้าแรก, ส่งเอกสาร, เมนู ⋯ (ไปคลัง, ย้ายไปถังขยะ)
ปุ่มย้อนกลับของมือถือพากลับหน้าแรก โค้ดอยู่ใน `pwa-home.js` (ใช้ปุ่มเดิมของฟอร์ม ไม่แตะรูปแบบข้อมูลหรือไฟล์ส่งงาน)

## ข้อมูลอยู่ที่ไหน
เก็บในเบราว์เซอร์ของเครื่องนั้น (IndexedDB) ไม่ส่งออกไปที่ไหน แต่ละเครื่อง/แต่ละเบราว์เซอร์แยกกัน
ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลจะหาย โดยเฉพาะ iPhone ที่ไม่ได้ติดตั้งลงหน้าจอโฮม
**ควรกด คลังเอกสาร > สำรองข้อมูล (ZIP) เป็นประจำ** และใช้ปุ่ม "นำเข้า" ในคลังเอกสารเพื่อกู้คืน/ย้ายไปเครื่องอื่น

## อัปเดตแอป
อัปโหลดไฟล์ใหม่ทับ แล้วแก้เลข `V='qc-v11'` ใน sw.js เป็นเลขถัดไป เพื่อให้เครื่องที่ติดตั้งแล้วดึงเวอร์ชันใหม่

## เตรียมไว้สำหรับออนไลน์ในอนาคต
- ฟอร์มคุยกับที่เก็บข้อมูลผ่านชั้นเดียวคือ `pwa-shell.js` (db / user / assets / downloads) เมื่อจะเปลี่ยนเป็นออนไลน์ แทนที่ไฟล์นี้ด้วยตัวเชื่อมกับเซิร์ฟเวอร์ ฟอร์มไม่ต้องแก้
- ทุกเอกสารมี id ที่สร้างฝั่งเครื่อง, rev, updatedAt, deletedAt (ลบแบบซ่อน) ซึ่งเอื้อต่อการซิงก์และรวมข้อมูลหลายเครื่อง
- ไฟล์สำรอง ZIP เป็นรูปแบบแยกตาราง (projects, parties, folders, inspections, items, photos) นำเข้าฐานข้อมูลบริษัทได้ตรง ๆ
- สิ่งที่ยังต้องทำเมื่อออนไลน์จริง: ระบบล็อกอิน สิทธิ์ตามบทบาท การแก้ไขชนกันของหลายคน และที่เก็บรูปบนเซิร์ฟเวอร์

## ส่งงานเป็นไฟล์ (ส่ง/รับระหว่างมือถือ)
- ผู้ส่ง: กด "ส่งเอกสาร" เลือกเอกสาร กรอกชื่อผู้ส่งและรหัสผู้ตรวจ (เช่น A) กด "สร้างไฟล์ส่ง" ระบบสร้างไฟล์ ZIP แล้วตรวจซ้ำให้เอง จากนั้นกด "ส่ง…" เลือก LINE/อีเมล หรือ "บันทึกไฟล์" แล้วแนบเอง
- ผู้รับ: คลังเอกสาร > นำเข้า เลือกไฟล์ ระบบตรวจ SHA-256 ทุกไฟล์ก่อน ถ้าไม่ผ่านจะไม่นำเข้าอะไรเลย ถ้าผ่านจะแสดงสรุปให้กดยืนยัน แล้วเขียนทั้งชุดในครั้งเดียว
- รหัสยืนยัน 8 หลัก ผู้ส่งและผู้รับต้องเห็นตรงกัน
- ฉบับเดียวกันที่ส่งซ้ำ: ถ้าผู้รับยังไม่ได้แก้ จะอัปเดต ถ้าผู้รับแก้แล้วจะเก็บไว้ทั้งสองฉบับ (ต่อท้ายเลขที่ด้วย "(รับเข้า)") ไม่เขียนทับ
- รหัสผู้ตรวจจะนำหน้าเลขที่เอกสารใหม่ (เช่น A-INS-006) กันเลขซ้ำระหว่างผู้ตรวจหลายคน
- นามสกุล .qcz ใช้แทน .zip ได้ถ้า LINE/อีเมลไม่รับ .zip นำเข้าได้เหมือนกัน
- ข้อจำกัด: แอปรู้ไม่ได้ว่า LINE/อีเมลส่งถึงปลายทางหรือไม่ ใช้รหัสยืนยันเทียบกัน
- ไฟล์สำรองรุ่นเก่า (qc-backup-*.zip) นำเข้าได้ แต่ตรวจได้เพียง CRC ของไฟล์ ไม่มีรหัส SHA-256

## รูปถ่าย
- ย่อรูปอัตโนมัติ ด้านยาวไม่เกิน 1280 px (ไม่ขยายรูปเล็ก) และปรับคุณภาพให้ไฟล์ไม่เกินราว 320 KB
- กรอบรูปในฟอร์มและใน PDF ปรับตามทรงรูป: แนวนอน 4:3, จอกว้าง 16:9, จัตุรัส 1:1, แนวตั้ง 3:4 แสดงทั้งภาพไม่ตัดขอบ
- รูปเก่าที่เก็บไว้ไม่ถูกแก้ไฟล์ เปลี่ยนแค่การแสดงผล

## อัปเดตแอป
แอปดึงไฟล์ใหม่ทันทีเมื่อมีเน็ต (รอไม่เกิน 3 วินาที ถ้าสัญญาณช้าจะใช้ไฟล์ที่เก็บไว้) ถ้าอัปโหลดไฟล์ใหม่แล้วยังเห็นของเก่า ให้ปิดแอปให้สนิทแล้วเปิดใหม่ 1-2 ครั้ง
